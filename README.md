# production-linux-runbooks
A collection of practical runbooks to make building secure, maintainable Linux systems easier.

These runbooks are based on systems and configurations that I deploy. I write them to be clear enough to follow from beginning to end while also explaining the reasoning behind important decisions. My goal is to share useful documentation that can help people of all skill levels build reliable systems of their own.

## Validation
I validate each runbook from beginning to end before considering it complete. Each runbook records the platform used for testing and the date it was last validated.
